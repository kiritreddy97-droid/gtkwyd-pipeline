## The algorithm
The process starts with a 2D representation of your face, a grid of pixels. This grid is then compared to a database of known faces, using a technique called template matching.
[[grid of pixels]] [[computer screen with face templates]]

## The feature extraction
The algorithm extracts 130 unique features from your face, including the shape of your eyes, nose, and mouth, as well as the distance between them. These features are then used to create a unique "face map" that can be compared to other faces.
[[face map]] [[mathematical equations]]

## The comparison
The face map is then compared to the face map of the person in the database, using a technique called distance metric. The algorithm returns a score that indicates how similar the two faces are.
