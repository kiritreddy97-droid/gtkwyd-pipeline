## The technique
You're more likely to accept a second, smaller request after being asked for a bigger favor. This is the door-in-the-face technique, a clever tactic used by salespeople and politicians.
[[door in the face]] [[person being asked for a large favour]]

## How it works
The first request is made, and if refused, the second, smaller request is made. The goal is to make the second request seem more reasonable by comparison.
[[person being asked for a smaller favour]] [[comparison chart]]

## The psychology
The brain is wired to respond negatively to the first request, making the second one more acceptable. This is because the first request is perceived as an invasion of personal space.
